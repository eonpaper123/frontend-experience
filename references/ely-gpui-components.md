# Ely GPUI Components

Use [ELY-Open-Source/Ely-GPUI-Components](https://github.com/ELY-Open-Source/Ely-GPUI-Components) as an optional visual and component reference for Rust applications built with GPUI. It is not a drop-in library for React, DOM applications, or other UI frameworks.

The repository presents component examples and stories for GPUI, including semantic color and light/dark treatments. Before considering reuse, inspect the current source and API against the target project's GPUI version, and check the license of each dependency and asset. The project's [MIT license](https://github.com/ELY-Open-Source/Ely-GPUI-Components/blob/main/LICENSE) does not automatically cover bundled third-party icons or fonts.

This reference adds no dependency and makes no claim that a component has been installed, tested, or integrated. Keep the current project framework unless a concrete product requirement calls for a change.
