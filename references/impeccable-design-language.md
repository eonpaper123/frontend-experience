# Impeccable design review

[Impeccable](https://github.com/pbakaus/impeccable) is an optional set of design-direction commands and deterministic checks for existing web products. Use individual checks to find concrete issues; they are not a complete aesthetic standard, a replacement design system, or a reason to redesign a product.

Before using its documentation or setup commands, inspect the project's existing product and design-system documents and preserve their decisions. Do not overwrite them. The repository is licensed under [Apache-2.0](https://github.com/pbakaus/impeccable/blob/main/LICENSE); review current terms and tool behavior before adopting it.

The project documents command families for changing visual emphasis, reviewing a page, polishing, adapting, and checking rendered or source-level properties. Choose only the operation relevant to the task. A CLI or browser check can surface likely issues, but cannot replace inspection of hierarchy, brand fit, accessibility, interaction states, and target sizes. This reference does not install Impeccable, add a hook, or authorize changes to project files.
