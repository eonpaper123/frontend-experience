# Classic Contrasting Color Pairs

Use this candidate pool only when the user has not specified colors and the existing brand or project design system does not already supply them. Choose one pair for the intended mood, content, and surface instead of generating a generic purple-blue gradient. Keep an established brand recognizable; this reference does not authorize recoloring an existing product.

## Apply one pair deliberately

- **Establish dominance.** Start with roughly 60-70% dominant, 20-30% supporting, and 5-10% accent visual weight. Choose values that total 100%, such as 65/25/10, instead of splitting the canvas into two competing 50/50 fields. These are composition roles, not three required chromatic inks or pixel quotas. In UI, a neutral surface can own the dominant role while the selected pair appears in smaller support and accent roles.
- **Match the surface.** A poster or cover can use a dark field and bright focal point. UI usually needs neutral surfaces, readable neutral body text, and selected colors on suitable actions, status treatments, or data-series accents. Preserve established status meanings and required chart-series distinctions instead of forcing every semantic color into the decorative pair. Image or poster generation still follows the host's applicable visual workflow.
- **Use one decorative pair at a time.** Do not combine several listed pairs in one composition. Neutral surfaces and text, plus necessary semantic colors, do not count as extra decorative pairs. Preserve the project's brand, focus indication, interaction states, and information density.
- **Measure real contrast.** Use a WCAG contrast tool on actual foreground/background combinations, including labels, links, status text, hover and focus states, transparency, and every supported theme. Light-on-dark and dark-on-light are starting heuristics, not evidence. No pair here is pre-approved for text. Record the measured result against the project's applicable accessibility target, and never use color as the only state or series cue.
- **Separate screen and print.** Treat the HEX values as sRGB screen references. Printed output depends on the destination profile, stock, ink, and proofing; the pair can shift or fall outside the printable gamut. Do not claim exact screen-to-print equivalence or invent a universal CMYK conversion.

## Provenance and acceptance boundary

The color labels, exact values, and composition preferences were supplied as a design reference. This file is an independently written usage guide; it contains no source images or third-party assets. The palette is neither a tested UI nor a print proof. Adoption still requires target-surface review and measured contrast for the chosen roles.
